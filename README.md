## 🚀 Descripción

**¡SONASTE!** es una aplicación web interactiva que permite **clonar la voz de personajes famosos** utilizando Inteligencia Artificial. Escribí tu mensaje y escuchalo con la voz de tus personajes favoritos como **Milei, Messi, Cristina, Gardel, Maradona** y muchos más.

### 🎯 ¿Para qué sirve?

- 🎉 **Saludos personalizados** con voz de famosos
- 📢 **Mensajes divertidos** para compartir en redes
- 🎭 **Creación de contenido** con voces clonadas
- 🎮 **Entretenimiento** para fiestas y eventos

---

## ✨ Características Principales

| Característica | Descripción |
|----------------|-------------|
| 🎤 **Clonación de voz** | Usa la API de Fish Audio para generar voces realistas |
| 👥 **20+ Personajes** | Milei, Messi, Cristina, Gardel, Maradona y más |
| 📱 **PWA Ready** | Instalable como app en tu dispositivo |
| 🌓 **Dark Mode** | Tema oscuro/claro con persistencia |
| 💾 **Cache inteligente** | Audios generados se guardan para reutilización |
| 📥 **Descarga de audios** | Guarda tus creaciones en formato MP3 |
| ⌨️ **Atajos de teclado** | `Ctrl+Enter` / `⌘+Enter` para generar voz |
| 📊 **Estadísticas** | Contador de frases generadas |
| 🔗 **Compartir** | Comparte en Twitter y WhatsApp |

## 🛠️ Tecnologías Utilizadas

### Frontend
- **HTML5** - Estructura semántica
- **CSS3** - Diseño responsivo con animaciones
- **JavaScript Vanilla** - Lógica de la aplicación
- **Inter Font** - Tipografía moderna

### Backend
- **Node.js** - Runtime
- **Fish Audio API** - Clonación de voz
- **Node-Cache** - Sistema de cache
- **Vercel** - Hosting y despliegue

### PWA
- **Service Worker** - Funcionamiento offline
- **Manifest** - Instalación como app
- **Web App Manifest** - Configuración nativa
